# chunder.github.io

Static personal website hosted with GitHub Pages. This repository contains the source code for the site available at [**https://chunder.github.io**](https://chunder.github.io). [web:1]

## Features

- Simple static site built with HTML, CSS and a small amount of JavaScript.
- Lightweight, fast-loading pages suitable for use as a personal homepage or project hub.
- Designed to be easy to extend with additional pages or components. [web:2]

## Tech stack

- **HTML** for structure
- **CSS** for styling and layout
- **JavaScript** for small interactive behaviors (where needed) [attached_file:1]

All assets are plain frontend files; there is no backend or build step required. [attached_file:1]

## Getting started

To run the site locally:

1. Clone this repository:
```bash
git clone https://github.com/MauroDeBruyn/chunder.git
cd chunder
```
2. Open `index.html` directly in your browser.

## Project structure

- `index.html` – main entry page of the site.
- `pictures/` – images and static media (if present).
- `.css` – stylesheet files (if present).
- `.js` – JavaScript files for interactive behavior (if present). [attached_file:1]

File and folder names may change as the project evolves. [web:2]

## Deployment

This site is deployed using GitHub Pages:

- **Source:** `main` branch (root directory)
- **URL:** https://chunder.github.io [attached_file:1]

Changes pushed to `main` are automatically picked up by GitHub Pages and redeployed after a short delay. [web:2]
